🪓 Только щепки летят

Несмотря на известную пословицу про то, что написано пером, в Python мы можем легко нарубить строки на списки строк. Для этого используется метод .split(). Если не указать никакого параметра, то строка разделится по пробельным символам (пробелы, табуляции, переводы строк).

Обратите внимание, что сами разделители исчезают.

Самое классное, что можно указать строку-разделитель (одну букву или целое предложение), по которой будет происходить нарезка строки:

Если разделитель в строке не встретится ни разу, то в результате получится список из одного элемента, в котором лежит исходная строка целиком.

Важный момент: если .split() встретит два разделителя подряд, всегда, кроме случаев вызова метода без указания разделителя, в итоговом списке будет элемент — пустая строка.

Но при этом:

По умолчанию .split() идёт по строке слева направо и делит её столько раз, сколько сможет. Но не всегда это то, что нам нужно. К счастью, Python мегасупергибкий и позволяет нам повлиять практически на всё.

Если нужно, чтобы строчка делилась на список строк по разделителю, но не больше какого-то числа раз — пожалуйста. Достаточно воспользоваться параметром maxsplit.

Если же нам захочется сделать пример выше несколько менее кровожадным и начать делить строчку не слева направо, а наоборот — справа налево, то достаточно воспользоваться методом rsplit().

Есть и ряд более экзотичных методов, которые, впрочем, в определённых ситуациях будут полезны и повысят читаемость кода:

.splitlines() — разделить текст в список построчно:

.partition() и .rpartition() — делят строку на три части: до разделителя, сам разделитель, всё остальное. Отличаются только тем, с какой стороны начинают искать разделитель.

🚀 Одной строкой

Когда лень вводить данные по одному элементу (а это всегда), Python позволяет сделать это одной строкой, а потом нарезать на части.

🪡 Из клочков

Если строчку можно разделить на список строк, то логично, что должна быть и обратная операция. И она есть! За сбор строки через определённый разделитель (в этом случае уместнее было бы говорить «соединитель», но...) из списка строк отвечает метод строки .join().

Довольно частая ошибка связана с тем, что начинающие разработчики пытаются вызвать метод .join() у списка, но это метод строки. Поэтому он вызывается у разделителя, через который мы хотим собрать элементы списка строк.

Отдельно радостно от того, что после последнего элемента разделитель не добавляется.

Разделитель, как вы наверняка догадываетесь, может быть не одним символом, а строкой любой длины.

Ещё раз: .join() — метод строки.

['a', 'b', 'c'].join(', ') # ❌ Ошибка!

Надо:

', '.join(['a', 'b', 'c']) # ✅

Другая распространённая ошибка использования .join() связана с тем, что корректно метод работает, только если в качестве параметра передан список строк. Если там есть элементы другого типа, то будет ошибка TypeError.

🤌 Сладкий сон перфекциониста

Есть такая категория людей, у которых малейший визуальный изъян вывода данных вызывает почти физический дискомфорт (а иногда и подёргивание глаза). Не осуждаем, а только советуем использовать методы строки для выравнивания, такие как .rjust(), .ljust() и .center().

Что делает rjust()?

Метод .rjust(width, fillchar=' ') возвращает строку, где исходная строка сдвинута вправо, а слева добавлены fillchar (по умолчанию пробелы), чтобы занять width символов.

Метод .ljust(), делает абсолютно то же самое, только сдвигает исходный текст к левому краю.
