Функции высшего порядка

Поговорим о высоком

Мы уже не раз упоминали, что Python не терпит дискриминации, поэтому если что-то можно сделать с одним объектом языка, то это же можно сделать и с другими объектами.

Сегодня мы поговорим о том, что с функциями можно обращаться точно так же, как, например, с целочисленными или строковыми объектами. Их можно:

присвоить переменной,

положить в список или словарь,

передать в другую функцию,

вернуть из функции.

📦 Кругом одни объекты

Первым делом давайте получим объект функции. Для этого достаточно написать имя функции без скобок. Это аналогично тому, что происходит со списками или строками: если вы пишете после имени списка квадратные скобки c индексом, то выполняется операция взятия элемента, не пишете скобки — получаете сам список. Пишете после функции круглые скобки с аргументами — она вызывается, не пишете — получаете саму функцию как объект.

Возможность записать функцию в переменную позволяет нам гибко управлять тем, какую функциональность мы хотим использовать. При этом нам не только не нужно будет менять код по всей программе, но не придётся даже изменять код функций. Достаточно переменной присвоить вместо одной функции другую.

Напишем программу, которая печатает списки либо просто через запятую, либо в «коробочках», в зависимости от значения переменной selected_formatting.

Умными словами, функция — это объект первого класса (first-class citizen).

🥸 У функции нет имени

Иногда писать def слишком многословно, особенно если функция крошечная и нужна один раз, например как параметр функции высшего порядка. Тут на выручку приходят lambda-функции, у которых даже имени нет.

Лямбда-функции — короткие безымянные (анонимные) функции, которые можно создавать инструкцией lambda <аргументы>: <выражение>.

Важно: тело lambda-функции — одно выражение. Нельзя туда пихать for, if как оператор и прочие многоходовочки. Но можно использовать тернарный оператор и вызовы других функций.

Строго говоря, то, что мы написали выше, хорошо только для иллюстрации, потому что при присваивании lambda-функции переменной мы, по сути, уже дали ей имя, а значит, стоило заменить её на обычную функцию. Присваивание безымянных функций переменным — нарушение PEP8, и это было продемонстрировано вам исключительно ради науки и в учебных целях.

Использовать lambda-функции разумно там, где функция маленькая, локальная и не нужна по имени. НО! Не превращайте код в «лямбда-лапшу». Если функция нетривиальна или используется в нескольких местах — лучше сделать полноценную функцию. Ваши будущие коллеги (и вы сами через неделю) скажут спасибо.

🔽 Отфильтровано

В Python есть несколько встроенных функций высшего порядка, некоторые из них вы уже даже использовали, просто не знали об этом. Но начнём с функции filter().

Функция filter() принимает функцию-критерий отбора элементов, а затем саму коллекцию элементов. Возвращает она «список» из элементов, удовлетворяющих критерию.

Простыми словами: каждый переданный элемент коллекции проходит через функцию-критерий, и если она возвращает True (или что-то, что можно интерпретировать аналогичным образом), то он попадает в результирующий «список». Иначе — нет.

🌟 Итог: такой порядок навели

Поздравляем, теперь вы владеете одним из самых элегантных инструментов Python — лямбда-функциями.

А ещё мы:

выяснили, что функции в Python — объекты первого класса,

попередавали функции в качестве аргументов другим функциям и функции же повозвращали,

дали определение функциям высшего порядка,

научились классно фильтровать, преобразовывать и сортировать данные.

Эти концепции — основа функционального программирования, которое делает код более декларативным, читаемым и выразительным. Теперь вместо циклов с кучей if-ов вы можете писать красивые цепочки преобразований.
